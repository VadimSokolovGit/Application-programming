# Лабораторная работа № 2. Валидатор ИНН

Консольная программа на Python проверяет формат и контрольные цифры российского ИНН. Для запуска нужен Python 3.10 или новее.

## Запуск

Из папки `ЛР 2` выполните команду и введите ИНН по приглашению программы.

```sh
python src/inn_validator/validator.py
```

Например, `7830002293` пройдёт проверку, а `7830002294` будет отклонён из-за ошибки в контрольной цифре.

## Правила проверки

1. ИНН должен быть строкой ровно из 10 или 12 цифр `0–9`. Пробелы, разделители и значения, состоящие только из нулей, отклоняются.
2. Для ИНН организации по первым девяти цифрам рассчитывается десятая, контрольная цифра.
3. Для ИНН физлица или ИП по первым десяти цифрам рассчитывается одиннадцатая. Для проверки двенадцатой цифры используются первые одиннадцать.
4. Для каждой контрольной цифры исходные цифры умножаются на соответствующие коэффициенты. Произведения складываются, затем вычисляется `(сумма % 11) % 10`. Результат сравнивается с цифрой в ИНН.

| Контрольная цифра | Коэффициенты |
| --- | --- |
| 10-я | `2, 4, 10, 3, 5, 9, 4, 6, 8` |
| 11-я | `7, 2, 4, 10, 3, 5, 9, 4, 6, 8` |
| 12-я | `3, 7, 2, 4, 10, 3, 5, 9, 4, 6, 8` |

Проверка выполняется локально. Для подтверждения присвоения ИНН используются сервисы ФНС.
